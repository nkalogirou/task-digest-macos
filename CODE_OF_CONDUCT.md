# Code of Conduct

## Our pledge

We pledge to make participation in Task Digest welcoming and harassment-free for everyone, regardless of background, identity, experience, or ability.

## Expected behavior

- Be respectful and constructive.
- Assume good intent while addressing impact clearly.
- Give actionable technical feedback.
- Respect privacy and never publish another person's work data or credentials.
- Accept reasonable moderation decisions.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, sexualized conduct, deliberate disclosure of private information, and sustained disruption are not acceptable.

## Enforcement

Report conduct concerns privately to the maintainers through the contact information on their GitHub profiles. Maintainers may edit or remove content, issue warnings, temporarily restrict participation, or permanently ban contributors when necessary.

This code applies in repository discussions, issues, pull requests, reviews, and project-related community spaces.
